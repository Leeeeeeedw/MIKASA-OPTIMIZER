三笠优选 MIKASA OPTIMIZER v1.0.5 — 使用说明
================================================

1. 启动
   安装版：运行「三笠优选_1.0.5_x64-setup.exe」，按向导安装后从开始菜单启动。
   便携版：解压「三笠优选_1.0.5_x64-portable.zip」，双击「三笠优选.exe」。

2. 首次使用
   - 软件每次启动默认进入夜间主题；顶部太阳/月亮按钮可临时切换浅色主题。
   - 等待顶部识别出「省份 · 运营商」；识别失败可点「重新检测」。
   - 进入「IP 来源」，按需导入候选：CM IP 库、GitHub Raw、Cloudflare 官方段、FOFA、本地 TXT，或直接点击七个社区公开源的「获取并导入」。
   - 返回「总览」，选择目标地区、每地区保留数量、端口、并发与延迟上限，点「开始优选」。

3. 结果
   - 扫描完成后进入「地区排名」查看实际 colo、延迟、下载速度与丢包率。
   - 正式结果只包含同时通过 TCP、HTTPS/colo、延迟与下载速度要求的 IP。
   - 首选地区（香港、台湾、日本、新加坡、韩国、法国、美国）单独展示；全球其他地区达标 IP 全部保留并标注实际地区，未知地区单独分组。
   - 节点位置按真实 colo 显示：香港、台湾、新加坡只显示自身；日本显示「日本东京 / 日本大阪」，美国显示「美国洛杉矶 / 美国圣何塞」等机房城市。
   - 「结果导出」支持选择单个地区，或选择「全部地区」把所有合格节点写入一个 TXT/CSV 文件。
   - 导出可设置最低下载速度（如 5 MB/s）与最高延迟，并勾选备注后缀：城市/国家、下载速度、延迟、colo、来源。
   - 示例：54.250.164.93:443#三笠优选 | 日本东京 | 下载 7.86MB/s
   - 左侧栏底部新增「打赏作者」，可查看微信 / 支付宝收款码。

3.1 GitHub 订阅上传
   - 点击「GitHub 上传 → 开始上传」，先选择上传范围：
     合并全部地区（一个 all.txt），或按地区拆分（all.txt + HK/all.txt + JP/all.txt ...）。
   - 与结果导出一样，可设置最低下载速度、最高延迟、TXT 备注字段和 TXT/CSV。
   - 上传完成后可直接复制 raw 直链或 jsDelivr CDN 直链。
   - 示例：https://raw.githubusercontent.com/xxx/xxx/main/mikasa-results/JP/all.txt
   - 把 xxx/xxx 替换成你自己的 GitHub 用户名和仓库名。
   - 私有仓库的 raw 链接需要登录或 Token，脚本无法匿名读取；要直接放进脚本，请把目标仓库改为 Public。
   - 文件放在 mikasa-results/ 子目录即可，不需要上传到仓库根目录。

3.2 速度单位与并发
   - 软件显示 MB/s；v2rayN 等客户端通常显示 Mbps，1 MB/s = 8 Mbps。
   - 多个 IP 同时下载会争抢本机出口带宽，批量测速速度会低于客户端单连接测速。
   - 设置页「下载测速并发」改为 1 时最接近客户端单连接结果；默认 4 更适合批量筛选。

4. 注意事项
   - 测速前后建议关闭 VPN、代理和 TUN，否则延迟与下载速度会受代理链路影响。
   - 本工具使用真实网络连接测试，不使用模拟数据；未发现目标地区 colo 时会如实显示 0。
   - Censys 与 GitHub 上传需要自行配置有效 Token；没有凭据时不会上传或伪造结果。
   - GitHub 仓库地址、分支与远程目录会本地保存；空仓库首次上传会自动创建初始 commit 与分支。
   - 上传失败时到「GitHub 上传 → 上传历史 → 说明」查看真实错误原因。
   - 社区源可能偶发请求失败；每个源独立记录状态，不会中断其他来源。

5. 数据位置
   数据库与日志：%APPDATA%\com.mikasa.optimizer\
   默认测速导出目录：%USERPROFILE%\Documents\三笠优选导出\
